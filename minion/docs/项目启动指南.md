## 🔧 环境要求

### 必需项

- **Python 3.8+**
- **pip** (Python 包管理器)

### 可选项（根据使用场景）

- **Docker** - 用于安全的 Python 代码执行环境（推荐）
- **Node.js 14+** - 用于 MCP (Model Context Protocol) 工具集
- **Qdrant** - 用于 mem0 向量存储（如果使用记忆功能）

## 🚀 快速开始

### 步骤 1: 克隆项目（如果还没有）

```bash
git clone https://github.com/femto/minion.git
cd minion
```

### 步骤 2: 安装项目依赖

```bash
# 方式 1: 开发模式安装（推荐）
pip install -e .

# 方式 2: 安装所有可选依赖
pip install -e ".[all]"

# 方式 3: 如果项目已发布到 PyPI
pip install minionx[all]
```

### 步骤 3: 配置文件和环境变量

```bash
# 复制配置文件模板
cp config/config.yaml.example config/config.yaml
cp config/.env.example config/.env
```

### 步骤 4: 编辑配置文件

#### 编辑 `config/config.yaml`

至少需要配置一个模型，例如：

```yaml
models:
  "default":
    api_type: "openai"
    base_url: "${DEFAULT_BASE_URL}"
    api_key: "${DEFAULT_API_KEY}"
    model: "${DEFAULT_MODEL}"
    temperature: 0
```

#### 编辑 `config/.env`

设置你的 API 密钥：

```bash
# 使用 OpenAI 兼容 API
DEFAULT_API_KEY=sk-your-api-key-here
DEFAULT_BASE_URL=https://api.openai.com/v1
DEFAULT_MODEL=gpt-4o

# 或使用其他服务（如 DeepSeek）
# DEFAULT_BASE_URL=https://api.deepseek.com/v1
# DEFAULT_MODEL=deepseek-chat
```

### 步骤 5: 运行第一个示例

```bash
# 运行简单的 CodeAgent 示例
python examples/code_agent_example.py

# 或运行 Brain 示例
python -c "from minion.main.brain import Brain; import asyncio; brain = Brain(); print(asyncio.run(brain.step('what is 2+2')))"
```

## 📝 详细配置

### Python 执行环境配置

Minion 支持三种 Python 执行环境：

#### 1. Docker 方式（推荐，最安全）

```bash
# 构建 Docker 镜像
docker build -t intercode-python -f docker/python.Dockerfile .

# 使用（代码中会自动使用）
from minion.main.brain import Brain
brain = Brain()  # 默认使用 Docker
```

#### 2. RPYC 方式（需要手动启动服务器）

```bash
# 启动 RPYC Python 服务器
python docker/utils/python_server.py --port 3007

# 在另一个终端使用
from minion.main.brain import Brain
from minion.main.rpyc_python_env import RpycPythonEnv
brain = Brain(python_env=RpycPythonEnv(port=3007))
```

#### 3. Local Python 方式（最简单，但需谨慎）

```python
from minion.main.brain import Brain
from minion.main.local_python_env import LocalPythonEnv

brain = Brain(python_env=LocalPythonEnv(verbose=False))
```

⚠️ **警告**: Local Python 方式会直接执行 LLM 生成的代码，可能存在安全风险。

### 可选服务配置

#### Qdrant（向量数据库，用于 mem0 记忆功能）

如果配置文件中启用了 mem0，需要启动 Qdrant：

```bash
# 使用 Docker 启动 Qdrant
docker run -p 6333:6333 -p 6334:6334 qdrant/qdrant

# 或使用 docker-compose
docker-compose up -d qdrant
```

配置文件中的 mem0 设置：

```yaml
mem0:
  vector_store:
    provider: "qdrant"
    config:
      collection_name: "mem0"
      host: "localhost"
      port: 6333
```

#### Node.js（用于 MCP 工具集）

如果使用 MCP 工具集，需要安装 Node.js：

```bash
# 检查是否已安装
node --version  # 需要 >= 14
npm --version

# 如果未安装，访问 https://nodejs.org/ 下载
```

## 🎯 启动方式

### 方式 1: 使用 CodeAgent（推荐）

```python
import asyncio
from minion.agents import CodeAgent

async def main():
    # 创建 Agent
    agent = await CodeAgent.create(
        name="My Assistant",
        llm="default",  # 使用配置中的模型名称
    )
    
    # 运行任务
    async for event in await agent.run_async("计算 123 * 456"):
        print(event)

asyncio.run(main())
```

### 方式 2: 使用 Brain

```python
import asyncio
from minion.main.brain import Brain

async def main():
    brain = Brain()
    obs, score, *_ = await brain.step(query="what's the solution 234*568")
    print(obs)

asyncio.run(main())
```

### 方式 3: 使用 Gradio Web UI

```bash
# 安装 Gradio（如果还没有）
pip install gradio

# 运行 Web UI
python examples/gradio_demo.py
```

然后在浏览器中打开显示的 URL（通常是 `http://127.0.0.1:7860`）

### 方式 4: 运行示例脚本

```bash
# CodeAgent 示例
python examples/code_agent_example.py

# MCP Agent 示例
python -m examples.mcp.mcp_agent_example

# Console Demo
python examples/console_demo.py

# Textual UI
python examples/textual_demo.py
```

## 🐛 常见问题

### 问题 1: 模块导入错误

**错误**: `ModuleNotFoundError: No module named 'minion'`

**解决方案**:
```bash
# 确保在项目根目录
cd /path/to/minion

# 重新安装
pip install -e .
```

### 问题 2: 配置文件未找到

**错误**: `FileNotFoundError: config/config.yaml`

**解决方案**:
```bash
cp config/config.yaml.example config/config.yaml
cp config/.env.example config/.env
```

### 问题 3: API 密钥错误

**错误**: `Authentication failed` 或 `Invalid API key`

**解决方案**:
1. 检查 `config/.env` 文件中的 API key 是否正确
2. 检查 `config/config.yaml` 中的环境变量引用是否正确
3. 确保 API key 有足够的配额

### 问题 4: Docker 相关错误

**错误**: `Cannot connect to Docker daemon`

**解决方案**:
- 确保 Docker 已安装并运行
- 或使用 LocalPythonEnv（不推荐用于生产环境）

### 问题 5: MCP Toolset 设置失败

**错误**: `MCP toolset setup failed`

**解决方案**:
```bash
# 检查 Node.js
node --version

# 手动测试 MCP server
npx -y @modelcontextprotocol/server-filesystem --help
```

### 问题 6: Qdrant 连接失败

**错误**: `Failed to connect to Qdrant`

**解决方案**:
```bash
# 启动 Qdrant
docker run -p 6333:6333 qdrant/qdrant

# 或禁用 mem0（如果不需要）
# 在 config.yaml 中注释掉 mem0 配置
```

## 💡 提示

1. **开发模式**: 使用 `pip install -e .` 安装，这样修改代码后无需重新安装
2. **配置文件优先级**: 项目配置 > 用户配置（`~/.minion/config.yaml`）
3. **环境变量**: 支持 `${VAR_NAME}` 语法在配置文件中使用环境变量
4. **日志**: 启动时会显示 `MINION_ROOT` 路径，用于调试配置问题
