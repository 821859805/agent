## 核心流程说明

### 执行流程（从用户请求到响应）

```
用户请求
    │
    ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 1. Agent.run_async(task)                                            │
│    • 初始化 AgentState                                               │
│    • 设置 Input 对象 (query, route, tools, stream)                   │
└───────────────────────────────────┬─────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 2. Brain.step(state)                                                 │
│    • 选择 Mind (left_mind/right_mind/hippocampus_mind)               │
│    • 处理图像输入                                                    │
│    • 设置工具和系统提示                                               │
└───────────────────────────────────┬─────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 3. Mind.step(input) -> ModeratorMinion.execute()                     │
│    • 根据 route 选择 Worker Minion                                   │
│    • 执行预处理 (Pre-processing Minion)                              │
│    • Worker 执行核心推理                                             │
│    • 检查结果，必要时触发改进                                         │
└───────────────────────────────────┬─────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 4. Worker Minion (CodeMinion/CoTMinion/etc.)                         │
│    • 构建提示词模板                                                  │
│    • 调用 LmpActionNode.execute()                                    │
│    • 处理工具调用（如有）                                             │
│    • 执行 Python 代码（CodeMinion）                                  │
└───────────────────────────────────┬─────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 5. LmpActionNode.execute()                                           │
│    • 格式化消息和工具                                                │
│    • 调用 LLM Provider.generate()                                    │
│    • 处理工具调用响应                                                │
│    • 返回结果或流式输出                                               │
└───────────────────────────────────┬─────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 6. 结果返回                                                          │
│    • AgentResponse (answer, score, terminated...)                    │
│    • 或 StreamChunk 流式输出                                         │
│    • 更新 AgentState.history                                         │
│    • 检查是否完成 (is_done)                                          │
└─────────────────────────────────────────────────────────────────────┘
```

## 关键设计模式

| 模式 | 应用位置 | 说明 |
|------|---------|------|
| **策略模式** | Minion 注册机制 | 不同 route 选择不同的 Worker Minion |
| **装饰器模式** | `@register_minion` | 自动注册 Minion 到全局注册表 |
| **工厂模式** | `create_llm_provider()` | 根据配置创建对应的 LLM Provider |
| **观察者模式** | 流式输出 | StreamChunk 逐块输出给 UI 层 |
| **模板方法** | BaseAgent | 定义 `step()` 骨架，子类重写 `execute_step()` |
| **组合模式** | Brain + Mind + Minion | 多层组合实现复杂推理 |

## 核心组件说明

### 1. Agent 层
- **BaseAgent**: 所有 Agent 的基类，提供完整的生命周期管理、工具管理、状态管理、流式输出、自动上下文压缩等功能
- **CodeAgent**: 专注于代码执行的 Agent，偏好使用 `code` route
- **ToolCallingAgent**: 支持工具调用的 Agent

### 2. Brain 层
- **Brain**: 核心推理引擎，管理 LLM、工具、Mind 和状态
- **Mind**: 心智类，代表不同的推理策略（left_mind 逻辑推理、right_mind 创造性思维、hippocampus_mind 记忆）

### 3. Minion 层
- **Minion**: 基础类，定义推理策略接口
- **ModeratorMinion**: 调度器，根据 route 选择合适的 Worker Minion
- **Worker Minions**: 具体执行推理的 Minion（CodeMinion、CoTMinion、PlanMinion 等）
- **Improver Minions**: 负责改进答案的 Minion

### 4. Action 层
- **LmpActionNode**: LLM 动作节点，负责执行 LLM 调用、处理工具调用、支持流式输出

### 5. Provider 层
- **BaseProvider**: LLM 提供者抽象基类
- 具体实现：OpenAI、Azure、Bedrock、LiteLLM 等

### 6. Tools 层
- **BaseTool / AsyncBaseTool**: 工具基类
- **Toolsets**: MCP、UTCP 工具集
- 内置工具：BashTool、BrowserTool、FileTool、WebSearchTool 等

### 7. Skills 层
- **Skill**: 技能定义，包含名称、描述、执行指令
- **SkillRegistry**: 技能注册器，管理技能的注册和查找
- **SkillLoader**: 从目录加载技能

### 8. Types 层
- **AgentState**: Agent 执行状态
- **AgentResponse**: Agent 响应结果
- **StreamChunk**: 流式输出块
- **Input**: 输入数据对象
- **History**: 对话历史
