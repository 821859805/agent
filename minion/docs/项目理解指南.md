# Minion 项目理解指南

## 📚 项目概述

**Minion** 是一个 AI Agent 的"大脑"（Brain）框架，设计用于执行各种类型的查询和任务。它的核心思想是模拟人类大脑的思考过程：接收问题 → 生成解决方案 → 验证 → 改进 → 输出最终结果。

## 🏗️ 核心架构

### 1. 核心组件层次结构

```
用户查询 (Query)
    ↓
Agent (CodeAgent/BaseAgent/ToolCallingAgent)
    ↓
Brain (大脑)
    ↓
Mind (左脑/右脑)
    ↓
Minion (具体执行者)
    ↓
最终结果 (Final Result)
```

### 2. 关键概念

#### **Brain（大脑）**
- **位置**: `minion/main/brain.py`
- **作用**: 项目的核心控制器，管理多个 Mind（左脑/右脑）
- **功能**:
  - 管理 Python 执行环境
  - 管理 LLM 配置
  - 协调不同 Mind 的工作
  - 处理工具（tools）和状态（state）

#### **Mind（思维）**
- **左脑（left_mind）**: 擅长逻辑推理、数学计算、语言分析
- **右脑（right_mind）**: 擅长创造性思维、模式识别
- **作用**: 根据任务类型选择合适的思维模式

#### **Minion（执行者）**
- **位置**: `minion/main/minion.py`
- **类型**:
  - **Worker Minion**: 执行具体任务（如 CodeMinion）
  - **Improver Minion**: 改进解决方案
  - **Pre-processing Minion**: 预处理输入
- **注册机制**: 使用装饰器 `@register_minion`、`@register_worker_minion` 等

#### **Agent（代理）**
- **位置**: `minion/agents/`
- **类型**:
  - **BaseAgent**: 基础代理，通用功能
  - **CodeAgent**: 专门用于代码执行和编程任务
  - **ToolCallingAgent**: 支持工具调用的代理
- **创建方式**: 使用 `.create()` 类方法（**重要**：不要直接使用构造函数）

## 🔄 工作流程

### 标准流程（参考 README.md）

```
1. Query（查询）→ 接收用户输入
2. Solution（解决方案）→ 生成解决方案
3. Check（检查）→ 验证解决方案
4. Improve（改进）→ 如果不满意，改进并重新生成
5. Final Result（最终结果）→ 输出满意结果
```

### 代码执行流程

```python
# 1. 创建 Brain
brain = Brain()

# 2. 创建 Agent（推荐使用 CodeAgent）
agent = await CodeAgent.create(
    name="My Agent",
    llm="your-model",
    tools=[...]  # 可选
)

# 3. 执行任务
async for event in await agent.run_async("your task here"):
    print(event)
```

## 💡 重要设计模式

### 1. 注册机制
```python
@register_worker_minion(name="code")
class CodeMinion(Minion):
    # ...
```

### 2. Agent 创建模式
```python
# ✅ 正确：使用 .create() 方法
agent = await CodeAgent.create(brain=brain, tools=[...])

# ❌ 错误：不要直接使用构造函数
agent = CodeAgent(brain=brain)
await agent.setup()
```

### 3. 路由机制
```python
# route 参数决定使用哪个 Minion
input_data = Input(query="...", route="code")  # 路由到 CodeMinion
```

### 4. 流式处理
```python
# run_async() 返回的是 async 函数，需要先 await
async for event in await agent.run_async("task"):
    # 处理 StreamChunk
    if isinstance(event, StreamChunk):
        # ...
```

## ❓ 常见问题

### Q: Brain 和 Agent 的区别？
A: Brain 是底层执行引擎，Agent 是高级封装，提供更友好的 API。

### Q: route 参数的作用？
A: route 决定使用哪个 Minion 来处理任务，如 `route='code'` 会使用 CodeMinion。

### Q: 如何添加自定义 Minion？
A: 继承 `Minion` 类，使用 `@register_worker_minion` 装饰器注册。

### Q: 如何添加自定义工具？
A: 创建工具类，在创建 Agent 时传入 `tools` 参数。

理解 Minion 项目的关键是：

2. **Minion** 是具体任务的执行者
3. **Agent** 是高级封装，提供易用接口
4. **路由机制** 决定使用哪个 Minion
5. **流式处理** 支持实时输出
